Overview

Weather Tracker IoT is a location-based smart weather monitoring system that retrieves real-time climate information from the Korea Meteorological Administration (KMA) API.

My Contribution

Summary:

  • Weather API integration and data processing
  • Real-time weather output on Wokwi serial monitor
  • OLED-based graphical visualization

1. Weather API Integration & Data Processing

I integrated the KMA weather API and processed XML data to extract temperature and humidity information.

2. Wokwi Serial Monitor Output

Weather data was displayed on the Wokwi serial monitor for real-time debugging and system monitoring.

3. OLED Graph Visualization

I implemented an OLED-based graph visualization to intuitively represent real-time weather changes.
