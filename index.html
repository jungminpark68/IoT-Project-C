Welcome to our Weather Tracker IoT Project

Overview

Weather Tracker IoT fetches weather data from the Korea Meteorological Administration (KMA) API Hub and simulates a custom GPS location. The system generates virtual sensors such as temperature, humidity, and light, and outputs all collected information to the serial monitor in VSCode via an ESP32 simulation (Wokwi).

Key features include simulated GPS location generation, virtual DHT22 sensor readings, LED indicators for weather states, and serial monitor output for debugging and visualization.

Method

System Flow:

  1. Retrieve weather XML data from KMA API Hub (https://apihub.kma.go.kr).
  2. Generate a random GPS location inside Korea and convert coordinates to city/district names.
  3. Simulate virtual sensors (DHT22: temperature & humidity, light sensor) and LED indicators.
  4. Print parsed weather and virtual sensor output to VSCode serial monitor for visualization and debugging.

Hardware / Software: Software-based IoT using VSCode and Wokwi ESP32 simulator. HTTPClient for API calls, XML parsing for weather data handling.

  • DHT22 for temperature and humidity simulation
  • LED indicators: Red -> Sunny, Blue -> Rainy, Yellow -> Cloudy
  • Serial Monitor displays location, weather, and virtual sensor values
