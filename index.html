Welcome to our Weather Tracker IoT Project

Overview

The system receives weather data from the Korea Meteorological Administration (KMA) through its API Hub, simulates a custom GPS location, and generates virtual sensors such as temperature, humidity, and light. All collected information will be shown on the serial monitor in VSCode.

Key Features:

  • Software-based IoT using VSCode and Wokwi (a virtual ESP32 simulator)
  • Retrieve data from KMA API Hub — apihub.kma.go.kr
  • GPS: generate a random location in Korea and convert coordinates to city and district names
  • LED indicators: Red → Sunny, Blue → Rainy, Yellow → Cloudy
  • DHT22: temperature & humidity sensor (simulated)
  • Display weather information and sensor data on the VSCode serial monitor

Method

Overview of system flow:

  1. Get weather data from KMA API Hub (XML data).
  2. Generate simulated GPS coordinates and convert to city/district.
  3. Create virtual sensors (DHT22 for temperature & humidity, light sensor).
  4. Output parsed data and virtual sensor readings to VSCode serial monitor (for visualization & debugging).

Tools & stack: VSCode + Wokwi (ESP32 simulator), HTTPClient for API calls, XML parsing, virtual sensors and serial monitor output.
