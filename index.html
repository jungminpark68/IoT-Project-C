Overview

Weather Tracker IoT is a location-based smart weather monitoring system that retrieves real-time climate information from the Korea Meteorological Administration (KMA) API. It automatically detects the current GPS location and visualizes weather data such as temperature, humidity, and light conditions through simulated sensors in Wokwi.

  • 🌦️ Location Check: Retrieves current coordinates and maps them to Korean region names.
  • 🌡️ Weather Display: Presents temperature and humidity in real time.
  • 💡 Light Sensor: Adjusts LED brightness according to weather conditions.

1) KMA Weather API Integration & Data Processing

I built the end-to-end pipeline for retrieving real-time weather information from the Korea Meteorological Administration (KMA) API. The response was parsed and converted into stable, display-ready values. In particular, I focused on extracting core parameters that are meaningful for users and downstream modules: temperature, humidity, rainfall, and wind direction/speed.

  • Handled request timing logic to avoid missing the latest update.
  • Parsed response fields into numeric values and normalized units/format.
  • Prepared the processed values to be reused by Serial output and OLED visualization.

Figure 1. Screenshot of parsed KMA API response showing extracted weather fields (Temp/Humid/Rain/Wind).


2) Real-time Output on Wokwi Serial Monitor

To make debugging reliable during simulation, I formatted and printed weather values in real time on the Wokwi Serial Monitor. This allowed us to verify that the API call and parsing logic were working correctly (and continuously updating) without relying only on the display.

  • Added labeled logs with units to avoid ambiguity (e.g., m/s, mm, °C).
  • Confirmed refresh timing and detected stale/missing values quickly.
  • Improved team debugging speed by making internal states visible immediately.

Figure 2. Serial Monitor output used to validate real-time updates and debugging of parsed weather values.


3) OLED Graph Visualization

I implemented an OLED-based graph visualization to represent changes in weather data over time. Instead of only printing raw numbers, the OLED graph helps users quickly interpret trends (e.g., temperature/humidity fluctuations) at a glance.

  • Mapped numeric ranges to pixel ranges for stable visualization.
  • Designed a compact layout suitable for small OLED resolution.
  • Refreshed the display smoothly to keep the UI readable.

Figure 3. OLED screen showing graph-based visualization for intuitive understanding of weather trends.

Method

System Flow:

  1. 1️⃣ Retrieve weather XML data from KMA API Hub using an HTTP client.
  2. 2️⃣ Generate random GPS coordinates in Korea for simulated location testing.
  3. 3️⃣ Convert coordinates to city and district names for weather mapping.
  4. 4️⃣ Simulate DHT22 (temperature/humidity), light sensors, and LEDs using Wokwi.
  5. 5️⃣ Print and visualize data in VSCode Serial Monitor for real-time tracking and debugging.

Tools Used: Wokwi Simulator, ESP32 microcontroller, KMA API, VSCode (C++ environment).
