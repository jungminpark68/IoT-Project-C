프로젝트 개요

Weather Tracker IoT는 기상청 API Hub(KMA)에서 실시간 날씨 데이터를 받아, ESP32 시뮬레이터(Wokwi) 상에서 가상의 GPS 좌표와 센서(온도·습도·조도)를 생성합니다. 데이터를 VSCode의 시리얼 모니터에 출력해 실시간 기상 정보를 시각화합니다.

주요 기능

  • Feeding Automation → Weather Automation: 기상청 데이터 자동 수집
  • GPS Simulation: 한국 내 랜덤 위치 생성 및 도시/구 변환
  • Virtual Sensors: 온도(DHT22), 습도, 조도 센서 모의 출력
  • LED Status: Red – Sunny, Blue – Rainy, Yellow – Cloudy
  • Serial Monitor: 데이터 통합 출력 및 디버깅 기능

사용 기술 및 도구

  • VSCode + Wokwi (ESP32 Simulator)
  • HTTPClient / KMA API Hub (https://apihub.kma.go.kr)
  • DHT22 Sensor / LED Indicators
  • Serial Monitor / GPS Parsing / XML Data Handling
