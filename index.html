Welcome to Our Weather Tracker IoT Project

Overview

The Weather Tracker IoT system retrieves real-time weather data from the KMA API Hub, simulates virtual sensors, and visualizes environmental conditions using ESP32 (Wokwi) and VSCode.

  • Virtual IoT system using Wokwi & VSCode
  • Weather data from KMA API Hub
  • Random GPS coordinates converted to Korean region names
  • Simulated DHT22 & light sensors
  • LED indicators for weather conditions (Sunny, Cloudy, Rainy)
  • Data displayed on serial monitor

Method

  1. Request weather data from the KMA API Hub (XML format).
  2. Parse XML data to extract temperature, humidity, and weather status.
  3. Simulate virtual sensors using Wokwi (ESP32).
  4. Generate a random GPS location within South Korea.
  5. Display combined data through serial output.
