Overview

Weather Tracker IoT retrieves weather data from the Korea Meteorological Administration's API Hub and simulates a virtual IoT environment using an ESP32 emulator (Wokwi). The system generates virtual sensors (temperature, humidity, light) and simulates GPS locations; all outputs are printed to the VSCode serial monitor for visualization and debugging.

Key features

  • Software-based IoT using VSCode + Wokwi (ESP32)
  • Retrieve weather XML via KMA API Hub (apihub.kma.go.kr)
  • Random GPS generation & reverse mapping to Korean regions
  • Virtual sensors (DHT22 for temperature & humidity, simulated light sensor)
  • LED indicators: Red (Sunny) / Blue (Rainy) / Yellow (Cloudy)
  • Serial monitor outputs aggregated weather & sensor data

Method

  1. Request weather data (XML) from the KMA API Hub.
  2. Parse XML to extract weather, temperature, humidity.
  3. Simulate GPS coordinates and virtual sensors on Wokwi (ESP32).
  4. Visualize and debug via VSCode serial monitor output.
