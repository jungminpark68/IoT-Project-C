Overview

Weather Tracker IoT is a location-based climate monitoring system built using Wokwi and the Korea Meteorological Administration (KMA) API.

(Check Location): Uses GPS to determine the current location.
(Show Weather): Displays real-time weather information based on the detected area.

[Overview image removed]

Method

  1. Retrieve weather XML data from KMA API Hub.
  2. Generate random GPS coordinates in Korea and map them to locations.
  3. Simulate virtual sensors (DHT22, light sensor) and LED indicators.
  4. Display parsed data in the VSCode serial monitor.
