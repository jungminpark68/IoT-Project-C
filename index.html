Overview

Weather Tracker IoT retrieves weather data from the Korea Meteorological Administration's API Hub and simulates a virtual IoT environment using an ESP32 emulator (Wokwi). The system generates virtual sensors (temperature, humidity, light) and GPS coordinates; all data is displayed on the VSCode serial monitor.

  • Virtual IoT system using Wokwi & VSCode
  • Weather data via KMA API Hub
  • Random GPS + reverse mapping to Korean region
  • Simulated DHT22 & light sensors
  • LED indicators: Red (Sunny) / Blue (Rainy) / Yellow (Cloudy)

Method

  1. Request weather data from the KMA API Hub.
  2. Parse XML to extract weather, temperature, humidity.
  3. Simulate GPS coordinates and sensors on Wokwi (ESP32).
  4. Display data on VSCode Serial Monitor.
