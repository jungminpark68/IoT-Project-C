Overview

Weather Tracker IoT is a location-based smart weather monitoring system that retrieves real-time climate information from the Korea Meteorological Administration (KMA) API.

My Contribution (Jeongmin Park)

  • KMA weather API integration and data processing
  • Real-time output on Wokwi Serial Monitor
  • OLED-based weather graph visualization

1. Weather API Integration

Parsed real-time weather data (temperature, humidity, rainfall, wind) from the KMA API and prepared values for visualization.

2. Serial Monitor Output

Printed structured weather logs to the Wokwi Serial Monitor for debugging and validation.

3. OLED Graph Visualization

Implemented OLED-based graph visualization to show weather trends intuitively.
