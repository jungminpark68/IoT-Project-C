Overview

The system receives weather data from the KMA API Hub, simulates GPS and sensors, and outputs results via VSCode serial monitor.

  • Software IoT using VSCode & Wokwi
  • KMA API data retrieval
  • Simulated GPS & virtual sensors
  • Weather visualization & logging

Method

  1. Fetch XML data from KMA API Hub.
  2. Parse data and simulate sensors (DHT22, Light).
  3. Generate random GPS coordinates.
  4. Display data on serial monitor.
