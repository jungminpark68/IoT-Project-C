Welcome to our Weather Tracker IoT Project

Overview

The system receives weather data from the Korea Meteorological Administration (KMA) through its API Hub, simulates a custom GPS location, and generates virtual sensors such as temperature, humidity, and light. All collected information is displayed on the serial monitor in VSCode.

Key Features

  • Software-based IoT using VSCode and Wokwi (virtual ESP32 simulator)
  • Get data from KMA API Hub — https://apihub.kma.go.kr
  • GPS: generate a random location in Korea and convert coordinates to city and district names
  • Virtual sensors: DHT22 (temperature & humidity), light sensor
  • LED indicators: Red → Sunny, Blue → Rainy, Yellow → Cloudy
  • Display location, weather, and temperature on serial monitor

Technologies Used

  1. VSCode + Wokwi
  2. HTTPClient
  3. Sensors (DHT22, LED)
  4. Serial Monitor

Method

System Flow:

  1. Retrieve weather XML data from KMA API Hub (https://apihub.kma.go.kr)
  2. Generate a random GPS location and convert coordinates to a readable address
  3. Simulate virtual sensors (temperature, humidity, light) with corresponding LED status
  4. Display combined data (weather + sensors) on the VSCode serial monitor
