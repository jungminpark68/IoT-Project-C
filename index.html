Overview

My Contribution

Summary:

  • Weather API integration and XML data processing
  • Real-time weather data output on Wokwi Serial Monitor
  • OLED-based real-time graph visualization

1. Weather API Integration & Data Processing

I integrated the Korea Meteorological Administration (KMA) weather API and implemented XML parsing logic to extract key parameters such as temperature, humidity, rainfall, and wind speed.

2. Wokwi Serial Monitor Output

The processed weather data was formatted and displayed on the Wokwi Serial Monitor in real time, enabling effective monitoring and debugging.

3. OLED-Based Graph Visualization

I implemented an OLED-based graph visualization to display real-time changes in weather data, allowing users to intuitively understand trends.
